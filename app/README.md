# 应用层边界说明

`app/` 是一期运行入口，承接接口、页面路由和页面动作桥接。

## 当前已落地

- `api/`：6 个核心模块最小接口入口（列表/详情/创建/主链推进/发布检查/复盘创建）。
- `web/pages/`：6 个核心页面骨架（发现台、选题池、内容工坊、图片工坊、发布检查、复盘台）。
- `web/action_bridge.py`：页面动作统一走 `POST /web/actions/{action_code}`，转调既有 API。
- `main.py`：本地 HTTP 入口，统一承接页面路由与 API 调用。

## 当前边界

- 不扩展复杂接口规范、权限系统、复杂分页筛选与复杂错误码体系。
- 不引入复杂前端状态管理框架或样式系统重构。
- 页面与接口只做一期最小联动闭环，后续增强另起任务卡。
