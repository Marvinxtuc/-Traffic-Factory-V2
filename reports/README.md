# reports 目录留痕规则

## 命名规则
- 允许入库的报告文件：`v2_*.md`
- 其他文件默认不入库（仍由 `.gitignore` 忽略）

## 最小模板字段
每份 `v2_*.md` 至少包含以下字段，便于审计复核：

1. `日期`：`YYYY-MM-DD`
2. `基线`：分支/提交/工作区状态说明
3. `执行命令`：完整命令列表（可复现）
4. `结果摘要`：通过/失败/阻塞
5. `问题清单`：按 P0/P1/P2/P3 列问题
6. `结论`：是否通过本轮验收
7. `回滚口径`：失败时如何回退

## 使用说明
- 新增报告前先确认文件名匹配 `v2_*.md`。
- 报告内容必须可复现，不接受“口头通过”。
