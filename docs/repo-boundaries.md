# 仓库边界说明

## 文档目标

本文件只定义当前仓库的工程边界、运行边界和测试边界，不扩展业务需求本身。

## 当前代码边界

- `app/`：接口入口、页面路由、页面动作桥接与本地运行入口。
- `domain/`：领域对象、规则与仓储实现。
- `services/`：主链服务、发布检查服务、复盘服务与能力桥接服务。
- `workflows/`：主链编排（信号到复盘）。
- `skills/`、`adapters/providers/`：能力层最小骨架与 provider 占位。

不在本阶段引入复杂权限体系、复杂状态管理框架或二期功能模块。

## 测试边界

- 测试数据库只能来自临时测试目录。
- 测试不得读写 `runtime/`、`reports/`、`artifacts/`、`data/runtime/`。
- 测试数据来源限定在 `data/testdata/` 与测试夹具。
- 数据库连接必须显式关闭，避免 `sqlite3 ResourceWarning` 告警污染验收观感。

## 数据与运行边界

- `data/seeds/`：可提交种子数据。
- `data/testdata/`：可提交测试夹具。
- `data/runtime/`：本地运行数据库目录。
- `runtime/`：本地缓存与临时状态。
- `reports/`：受控报告文件。
- `artifacts/`：导出文件与运行产物。

上述运行目录不应写入未受控临时产物。

## 页面设计资产边界

- `stitch/` 仅存放设计输入资产，不作为运行页面目录。
- 运行页面固定落在 `app/web/pages/`。
